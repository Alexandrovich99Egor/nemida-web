# Design Direction

## Visual Style

The product should use a dark, investigative, cybersecurity-inspired aesthetic.

The mood should feel like a serious intelligence console rather than a generic SaaS dashboard. The interface can feel sharp, technical, and atmospheric, but it must remain readable and operational.

## Design Keywords

- Dark hacking aesthetic.
- Investigation console.
- Social graph intelligence.
- Timeline monitoring.
- Signal analysis.
- High contrast.
- Minimal noise.
- Dense but readable data.

## Interface Principles

- Prefer dark backgrounds with clear contrast for text, tables, forms, and charts.
- Use restrained accent colors for state and priority, not decorative gradients everywhere.
- Make timelines, event feeds, account metadata, and relationship changes easy to scan.
- Use compact layouts for operational screens.
- Prioritize filtering, search, timestamps, source labels, and change history.
- Avoid marketing-style hero sections inside admin workflows.

## Filament Admin Direction

The first UI layer is the Filament admin panel. It should be customized toward the dark investigation aesthetic while keeping Filament's standard ergonomics.

Expected admin experience:

- Dark theme by default.
- Clear navigation groups for subjects, accounts, events, sources, and reports.
- Table-heavy screens with strong filters and badges.
- Detail pages with timelines and source evidence.
- Minimal decorative UI unless it improves comprehension.

## Product Name

The product name is `dox.sh`. The visual language should treat the name like a command-line tool and intelligence console brand.

## Marketing Direction

If a public website is added later, the style can lean into a darker documentary or investigation feel. It should communicate legal monitoring, intelligence, and signal tracking without implying illegal hacking or abuse.
